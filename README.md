# RESUMATE AI — AI Resume Analyzer & ATS Score Checker

RESUMATE AI is a full-stack Python & Streamlit application powered by the Google Gemini API. It evaluates candidate resumes (PDF) against specific job descriptions to compute an estimated ATS compatibility score, uncover matched and missing skills, visualize keyword coverage, and generate personalized improvement plans and downloadable PDF/JSON reports.

---

## Key Features

- **Modern Glassmorphism UI**: Dark navy and deep violet interface with electric blue and purple accents, interactive Plotly gauges/charts, and responsive design.
- **Secure PDF Processing (`pypdf`)**:
  - Validates `.pdf` extension, `%PDF-` magic header, and 10 MB maximum file size.
  - Detects and gracefully reports corrupted, password-protected, empty, and scanned/image-only PDFs (noting that OCR is not supported).
  - Parses PDFs in memory without permanently storing uploaded resume files.
- **Google Gemini AI Analysis Engine (`google-genai`)**:
  - Evaluates resumes against job descriptions using structured JSON output validated by Pydantic.
  - Distinguishes between explicitly stated skills and context-inferred skills without fabricating qualifications.
  - Treats resume and job description contents as untrusted input to defend against prompt injection.
- **Rich Results Dashboard**:
  - Circular Plotly ATS Compatibility Score gauge (`0–100`) with calibrated match levels (`Excellent Match`, `Good Match`, `Moderate Match`, `Needs Improvement`).
  - Matching skills badges and missing skills cards with explanations of why each skill matters for the target role.
  - Keyword coverage breakdown chart, resume strengths, experience/education alignment, and final assessment.
  - Exactly 5 personalized improvement suggestions and a truthful AI-generated professional summary with one-click copy buttons.
- **Exports & Local History**:
  - Download styled multi-section **PDF Reports** (ReportLab) and structured **JSON** exports.
  - Local SQLite **Analysis History** (`data/resumate_history.db`) with search, report reopening, and delete/clear controls (without storing raw resume PDFs).

## Installation & Setup

### 1. Create and Activate a Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows PowerShell
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Copy `.env.example` to `.env` (or configure environment variables in your deployment platform):

```bash
cp .env.example .env
```

Edit `.env` and provide your Google Gemini API key:

```env
GEMINI_API_KEY="your_actual_gemini_api_key"
GEMINI_MODEL="gemini-4-hydrogen"
```

> **Security Notice:** Never commit `.env` or hardcode `GEMINI_API_KEY` in source files.

---

## Running the Application

Start the Streamlit server:

```bash
streamlit run app.py
```

Or specify a custom host and port (e.g., port 3000):

```bash
streamlit run app.py --server.port 3000 --server.address 0.0.0.0
```

Then open your browser to `http://localhost:8501` (or `http://localhost:3000`).

## Disclaimer

ATS scores generated by RESUMATE AI are AI-estimated compatibility benchmarks comparing a resume against a pasted job description. They are designed for educational and career preparation purposes and do not represent the exact proprietary scoring algorithm of any specific employer's Applicant Tracking System.
